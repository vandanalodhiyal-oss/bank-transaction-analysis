# Bank Transaction Analysis 

## Goal
Data ko saaf karna, samajhna aur charts ke saath pehle insights nikalna.

## Steps
1. Libraries import karna (pandas, numpy, matplotlib, seaborn)
2. CSV load karna, shape / head / info dekhna
3. Missing values aur duplicates check karna
4. Dates ko date type mein badalna
   (TransactionDate, PreviousTransactionDate)
5. Naye columns banana: month, day of week, age group
6. Basic analysis:
   - transaction type ka count
   - channel ke hisaab se count
   - location ke hisaab se count
   - average amount
   - age group aur occupation ke hisaab se amount
7. Unusual transactions dhundna
   (bahut bada amount, LoginAttempts zyada)
8. Mahine ka trend chart
9. Cleaned CSV save karna: bank_transactions_clean.csv
